# tomorrowUFBA

A recreation of the Tomorrow UFBA website, built in 2 days during a web programming competition at the Federal University of Bahia. The team of 8 developers, led by Cauã Moraes, placed first.

Tomorrow is an initiative between UFBA and Positivo Tecnologia that offers free technology training courses.

## Stack

HTML5, CSS3, JavaScript, PNPM.

## Run

```sh
pnpm install
pnpm run dev
```

Or with Python's built-in server:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
