# Tomorrow UFBA - Recriação do Site

## 📋 Descrição

Este projeto é uma recriação fiel do site oficial do **Tomorrow UFBA**, desenvolvido como parte de um curso de programação web oferecido pelo Instituto de Computação da UFBA. O Tomorrow é uma iniciativa que une a UFBA e a Positivo Tecnologia para oferecer cursos gratuitos de capacitação em tecnologia.

O projeto foi criado em apenas **dois dias** durante uma competição intensa, onde nossa equipe de 8 desenvolvedores conseguiu a vitória ao apresentar a melhor recriação do site original. Sob minha liderança, conseguimos entregar uma solução completa e funcional que captura a essência do design e funcionalidades do Tomorrow UFBA.

## 🏆 Sobre a Competição

- **Duração**: 2 dias
- **Equipe**: 8 desenvolvedores
- **Liderança**: Cauã Moraes
- **Resultado**: Vitória na competição de recriação do site
- **Objetivo**: Recriar o site do Tomorrow UFBA com maior fidelidade e qualidade

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica das páginas
- **CSS3**: Estilização responsiva e moderna

## 🚀 Como Executar

### Pré-requisitos

- Node.js e PNPM instalados
- Ou Python 3 para servidor alternativo

### Instalação e Execução

1. Clone ou baixe o projeto
2. Navegue até a pasta do projeto:
   ```bash
   cd tomorrowUFBA/tomorrow
   ```

3. Instale as dependências:
   ```bash
   pnpm install
   ```

4. Execute o servidor de desenvolvimento:
   ```bash
   pnpm run dev
   ```

5. Abra seu navegador e acesse: `http://localhost:8000`

### Alternativa sem PNPM

Se preferir usar Python:
```bash
python3 -m http.server 8000
```
